This addon provides generic queue-backed lifecycle helpers for connector
inbound and outbound synchronization flows.

It owns reusable listeners, schedulers, dispatchers, and binding helpers
that transport-specific addons can feed into without coupling the
synchronization engine to a specific ingress mechanism.

Usage
=====

Provider addons consume this layer through component names, ``usage``,
and ``work_on(...)`` lookups.

Transport-specific addons should hand normalized inbound work into the
inbound listener and leave provider-specific routing and mapping in
provider addons.
